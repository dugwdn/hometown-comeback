# Hometown Comeback

A cozy browser game. You move back to your worn-down hometown (Millbrook), and rebuild one Main Street, one shop at a time. Version 1: one Main Street, five shops, 30 levels.

For: women 35 and older. Tone: warm, gentle humor, 1970s to 1990s nostalgia. No violence, no darkness.

Status: design only. No code yet. See `CLAUDE.md` for the plan and `docs/shops-and-characters.md` for the full story draft.

Handoff (how it was built, why, how to take over): see `HANDOFF.md`. Status: idea only, on hold.
